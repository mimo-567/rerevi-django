# Part (a) keyword practice

Part (a) keyword questions are a separate activity from the past-paper question bank. The past-paper bank remains without part (a) entries.

## Question generation

Use a fixed question stem: “What is meant by the term ‘{keyword}’?” Select a keyword randomly from the student's chosen topic. This is template based and does not use AI.

- Component 1: select from the key concepts for the chosen theme (Themes 1–4).
- Component 2 Christianity: use the same keyword pool across Beliefs and Practices.
- Component 3 Option 3 Islam: use the same keyword pool across Beliefs and Practices.

## Self-marking

Show the glossary's indicative content after the student answers. Students self-mark using this rule:

- 1 mark for a very simple definition or example.
- 2 marks for a developed definition, with or without an example.

Do not automatically grade the written response. The source PDF and structured concept list are `key-concepts-glossary.pdf` and `key_concepts.json`.
