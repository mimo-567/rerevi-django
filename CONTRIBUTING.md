# Contributing

Open an issue describing the problem or proposed improvement, then submit a focused pull request. Never include real student data or credentials in examples, screenshots or issue attachments.

This repository contains the standalone **Django ReRevi application**. English and History prototypes are outside its scope. The older Astro/Supabase project is a separate repository.

Preserve question provenance, matching mark schemes, the additional-practice opt-out, safe Markdown rendering, optional sharing and private deletion. Do not add live AI generation or automatic grading without an explicit product decision.

Run Django's system and migration checks for relevant changes. Check PDF output visually when changing booklet layout. Contributions to software are made under AGPL-3.0-only. Do not submit third-party educational material unless you have the necessary rights and provide attribution.
